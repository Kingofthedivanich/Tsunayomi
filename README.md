# Tsunayomi

Читалка манги, манхвы и маньхуа для Android с автопереводом страниц. Тысячи сайтов через встроенные источники,
парсеры Kotatsu и расширения Tachiyomi/Mihon, локальные файлы и свой сервер Komga — и перевод прямо поверх
картинки: офлайн через Google ML Kit или нейросетью по вашему ключу.

*A manga reader for Android that translates pages in place. Russian-language guide below; the app itself
speaks Russian and English.*

- Бесплатно и без рекламы, исходный код открыт ([GPL-3.0](LICENSE)).
- Ничего не отправляет само: ни аналитики, ни телеметрии. Сеть — только к источникам, которые вы открываете,
  и к сервису перевода, который вы выбрали.
- Android 8.0 и новее.

## Установка

1. Откройте страницу [Releases](https://github.com/Kingofthedivanich/Tsunayomi/releases/latest) и скачайте APK:
   - `tsunayomi-<версия>-arm64-v8a.apk` — почти все телефоны последних лет;
   - `armeabi-v7a` — старые 32-битные телефоны;
   - `x86_64` — эмуляторы и редкие планшеты на Intel.

   Не знаете, какой нужен, — берите `arm64-v8a`. Если не установится, попробуйте `armeabi-v7a`.
2. Разрешите браузеру или файловому менеджеру установку приложений, когда Android спросит.
3. Обновления ставятся поверх, данные сохраняются. Все версии подписаны одним ключом; контрольные суммы —
   в `SHA256SUMS.txt` рядом с APK.

## Быстрый старт

1. При первом запуске мастер предложит подключить ключ нейросети для перевода и скачать модель японского OCR.
   Всё можно пропустить и настроить позже — без ключей перевод работает офлайн через ML Kit.
2. Откройте **Обзор**, выберите источник (например, MangaDex или Remanga), найдите тайтл.
3. На странице тайтла нажмите **Добавить в библиотеку** и **Начать**.
4. В читалке коснитесь центра экрана и включите перевод кнопкой **Переводить страницы**.

## Где что находится

Внизу пять вкладок:

| Вкладка | Что там |
|---|---|
| **Библиотека** | Ваши тайтлы по категориям («Читаю», «Буду читать», «Прочитано», «Брошено» и свои), поиск, сортировка, прогресс «прочитано / всего» на обложках |
| **Обновления** | Новые главы тайтлов из библиотеки; потяните вниз, чтобы проверить сейчас |
| **Обзор** | Все источники; сверху — **Расширения** (иконка пазла) и **Глобальный поиск** (иконка лупы с глобусом) |
| **История** | Что и когда вы читали, с возвратом на ту же страницу |
| **Ещё** | Режим инкогнито, **Настройки**, **Резервное копирование**, **О приложении** |

Основные разделы **Ещё → Настройки**: оформление, язык приложения, папка с мангой и сервер Komga, обновления
библиотеки, режим чтения и кнопки громкости, перевод (**Конфигурация API**, способ перевода, язык, модель
японского OCR), безопасность и приватность.

## Источники манги

### Встроенные

MangaDex (все языки), Remanga (русский), Webtoons (английский), Naver Webtoon (корейский), Asura Scans
(английский). У MangaDex языки глав выбираются в фильтрах каталога.

### Парсеры Kotatsu

Около семидесяти сайтов из проекта [Kotatsu](https://github.com/KotatsuApp/kotatsu-parsers), которые мы
проверили: каталог открывается, главы и страницы грузятся. Они уже есть в **Обзоре**, ставить ничего не нужно.
Какие языки показывать — настройка языков на экране **Расширения**, она общая.

### Расширения Tachiyomi / Mihon

Подключают ещё сотни сайтов.

1. **Обзор → Расширения** (иконка пазла) → иконка репозиториев → вставьте ссылку на индекс репозитория.
   Самый большой — Keiyoushi: `https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json`.
2. Ставьте нужные расширения кнопкой **Установить** или все сразу — **Установить все** в заголовке списка.
   Список учитывает выбранные языки (иконка глобуса), поиск и переключатель **Показывать расширения 18+**.
3. Когда у расширения выходит новая версия, оно попадает в раздел **Обновления**; есть **Обновить все**.

Устанавливаются только расширения, подписанные ключом добавленного репозитория. Добавляйте репозитории,
которым доверяете: расширение — это код, который выполняется внутри приложения. У расширения с вариантом
«Все языки» в **Обзоре** показывается только он, без копий по отдельным языкам.

### Локальные файлы

**Ещё → Настройки → Папка с мангой** — выберите папку на телефоне. Поддерживаются папки с картинками, CBZ/ZIP,
CBR (только RAR4; RAR5 и архивы с паролем — нет), EPUB и PDF. Источник **Локальные файлы** — первый в **Обзоре**.

### Свой сервер Komga

**Ещё → Настройки → Сервер Komga**: адрес сервера и email с паролем или ключ API (его создают в Komga:
*Аккаунт → API-ключи*). Пароль и ключ хранятся на телефоне зашифрованными. Про Komga — [komga.org](https://komga.org).

### 18+

Источники и расширения для взрослых скрыты, пока не включён **Обзор → Расширения → Языки → Показывать
расширения 18+**. Переключатель общий для расширений и парсеров Kotatsu.

## Поиск, теги и авторы

- **В источнике** — лупа в каталоге ищет по названию; иконка воронки открывает фильтры источника.
- **По тегам в источнике** — иконка ярлыка в каталоге открывает шторку со всеми тегами источника. Отметьте
  один или несколько и нажмите **Найти**: покажутся тайтлы, у которых есть все отмеченные теги. Работает там, где
  сайт умеет искать по тегам (MangaDex, Remanga, большинство расширений и парсеров Kotatsu).
- **Глобальный поиск** (Обзор → лупа с глобусом) ищет во всех источниках сразу. Переключатель
  **Название | Тег | Автор** задаёт, по чему искать. Источники, которые так искать не умеют, перечислены внизу.
- **Из тайтла** — нажмите на тег или на автора (чипы с иконкой человека перед тегами) и выберите
  **Искать в <источник>** или **Искать во всех источниках**.

Теги ищутся по точному названию, поэтому английский «Romance» не найдёт русскую «Романтику» в другом источнике.

## Страница тайтла

- **Добавить в библиотеку** и **Категории** — куда положить тайтл.
- **Начать / Продолжить** — с первой главы или с места, где остановились.
- Долгое нажатие на главу — отметить прочитанной или непрочитанной, «прочитано до этой».
- Иконка загрузки у главы и в верхней панели — скачать главу, все непрочитанные, удалить скачанное.
- **Язык страниц** — на каком языке текст на картинках. Обычно определяется сам; поправьте, если перевод
  не срабатывает.
- **Глоссарий перевода** — как переводить имена и термины этого тайтла, чтобы они не менялись от главы к главе.
  Нейросетевые переводчики пополняют его сами.
- **⋮ → Открыть в WebView** — страница тайтла на сайте.

## Читалка

- Касание центра экрана — показать или скрыть панель; касание краёв — листать.
- Режимы: страницы слева направо, справа налево (классическая манга), вертикальные страницы, вебтун (лента).
  Режим по умолчанию — в настройках, для тайтла — в панели читалки.
- Кнопки громкости листают страницы, если это включено в **Настройки → Ридер**.
- **Переводить страницы / Показать оригинал** — включает и выключает перевод. Выбор запоминается для каждого
  тайтла отдельно.
- **Инкогнито** — глава не попадёт в историю и прогресс.

## Перевод страниц

Приложение находит текст на странице (OCR), переводит его и рисует перевод поверх пузырей. Переведённые страницы
кэшируются, повторно не переводятся.

| Способ | Нужен ключ | Интернет | Качество | Цена |
|---|---|---|---|---|
| **Google ML Kit** | нет | только чтобы один раз скачать языковой пакет (~30 МБ) | базовое | бесплатно |
| **Google Gemini** (рекомендуется) | да | да | высокое, учитывает контекст и глоссарий | бесплатный лимит в день |
| **OpenRouter** и другие OpenAI-совместимые | да (для Ollama — нет) | да | зависит от модели | есть бесплатные модели |
| **DeepL** | да | да | высокое | бесплатно 500 тыс. символов в месяц |

Настройка: **Ещё → Настройки → Перевод → Конфигурация API** — выберите сервис, вставьте ключ, нажмите
**Проверить**, затем **Сохранить**. Там же:

- **Переводить на** — язык перевода (по умолчанию — язык приложения).
- **Переводить автоматически** — включать перевод при открытии читалки.
- **Переводить при загрузке** — скачанные главы сразу переводятся и потом читаются в переводе без интернета.

Если онлайн-сервис недоступен (нет сети, кончился лимит), страница переводится офлайн через ML Kit, и читалка
об этом скажет.

### Японская манга: модель manga-ocr

Вертикальный японский текст ML Kit распознаёт плохо. Для него есть отдельная модель **manga-ocr** (~140 МБ,
работает офлайн): **Настройки → Перевод → Модель вертикального японского**. Нужна, только если читаете мангу
на японском.

### Ограничения

- Распознавание текста работает для японского, корейского, китайского и языков на латинице. Кириллицу OCR
  не читает, поэтому русские страницы на другой язык не переводятся.
- Рукописные шрифты, текст вне пузырей и звуки иногда распознаются с ошибками.

## Ключи API: где взять

Ключи хранятся на телефоне в зашифрованном виде и отправляются только в тот сервис, которому принадлежат.

### Google Gemini — бесплатно, рекомендуется

1. Откройте [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и войдите в аккаунт Google.
2. **Create API key** → скопируйте ключ.
3. В приложении: **Конфигурация API → Google Gemini** → вставьте → **Проверить**.

Бесплатного лимита хватает на обычное чтение. Когда у одной модели кончается дневной лимит, приложение
переключается на следующую (Flash-Lite 3.5 → Flash-Lite 3.1 → Gemma 4); порядок моделей меняется в настройках
перевода. В некоторых странах Google AI Studio недоступен — тогда выбирайте OpenRouter или DeepL.

### OpenRouter — бесплатные модели разных компаний

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) и создайте ключ в
   [Settings → Keys](https://openrouter.ai/settings/keys).
2. Бесплатные модели работают, только если в [Settings → Privacy](https://openrouter.ai/settings/privacy)
   разрешены провайдеры бесплатных моделей.
3. В приложении: **Конфигурация API → OpenRouter** → вставьте ключ, выберите модель с `:free` в названии →
   **Проверить**. Если модель перегружена (ошибка 429), нажмите одну из предложенных ниже.

У бесплатных моделей ограничено число запросов в день. Если проверка показывает ошибку с текстом от OpenRouter —
например, что модель недоступна в вашем регионе, — выберите другую модель.

### DeepL — 500 тысяч символов в месяц бесплатно

1. Зарегистрируйтесь на [deepl.com/pro-api](https://www.deepl.com/pro-api), тариф **DeepL API Free**
   (DeepL просит банковскую карту для проверки, но бесплатный тариф не списывает деньги).
2. Скопируйте ключ в разделе *Account → API Keys*; ключи бесплатного тарифа оканчиваются на `:fx`.
3. В приложении: **Конфигурация API → DeepL** → вставьте → **Проверить**. Расход лимита виден там же.

### Другие OpenAI-совместимые сервисы

В **Настройки → Перевод → Способ перевода → OpenAI-совместимый** есть готовые варианты:

| Сервис | Где взять ключ |
|---|---|
| DeepSeek | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) — платный, недорогой |
| Groq | [console.groq.com/keys](https://console.groq.com/keys) — есть бесплатный лимит |
| OpenAI | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) — платный |
| Ollama | ключ не нужен: модель на вашем компьютере ([ollama.com](https://ollama.com)), адрес вида `http://192.168.1.5:11434/v1` |

## Библиотека, обновления, загрузки

- **Категории** — «Читаю», «Буду читать», «Прочитано», «Брошено» создаются сами; свои — в библиотеке (иконка
  ярлыка): создать, переименовать, переставить, удалить.
- **Проверка новых глав** — **Настройки → Обновления библиотеки**: как часто проверять, только по Wi-Fi,
  скачивать ли новые главы сразу. Уведомления приходят только для тайтлов из категории «Читаю».
- **Загрузки** читаются без интернета; с включённым «Переводить при загрузке» — сразу в переводе.

## Резервная копия

**Ещё → Резервное копирование**: **Создать копию** сохраняет библиотеку, категории, прогресс, историю и глоссарии
в файл; **Восстановить** возвращает их, например на новом телефоне. Ключи API в копию не попадают — введите их
заново.

## Приватность и безопасность

- Приложение не собирает аналитику и не отправляет отчёты. Телеметрия, которую встраивают библиотеки Google
  (ML Kit), отключена.
- При падении отчёт сохраняется на телефоне; при следующем запуске вы увидите его целиком и сами решите,
  поделиться ли им.
- Текст страниц уходит только в выбранный онлайн-переводчик. С ML Kit всё остаётся на телефоне.
- **Ещё → Настройки → Безопасность и приватность**:
  - **Режим инкогнито** — не записывать историю и прогресс (быстрый переключатель есть и в **Ещё**, и в читалке);
  - **Блокировка приложения** — отпечаток, лицо или PIN-код при входе, с выбором задержки;
  - **Безопасный экран** — запрет скриншотов и скрытие окна в списке недавних приложений.

## Если что-то не работает

**Источник показывает Cloudflare или «проверку браузера».** Нажмите **Открыть в WebView**, пройдите проверку
на сайте и вернитесь — каталог перезагрузится сам. Вводить логин на сайте для этого не нужно.

**Источник не открывается совсем.** Сайт мог закрыться, сменить адрес или быть заблокирован у вашего провайдера.
Попробуйте другой источник с тем же тайтлом через глобальный поиск.

**«Ключ недействителен».** Скопируйте ключ заново целиком, без пробелов. Для OpenRouter проверьте настройки
приватности (см. выше).

**«Квота исчерпана» или ошибка 429.** Кончился бесплатный лимит или модель перегружена. Подождите, выберите
другую модель или другой сервис; пока что страницы переводятся через ML Kit.

**Перевод не появляется.** Проверьте **Язык страниц** на странице тайтла. Для японской манги скачайте manga-ocr.
Помните, что кириллицу OCR не распознаёт.

**Расширение «не подписано ни одним из добавленных репозиториев».** Добавьте репозиторий, из которого оно, или
удалите расширение.

**Нашли ошибку?** Создайте [issue](https://github.com/Kingofthedivanich/Tsunayomi/issues): что делали, что
ожидали, что получилось, версия приложения и источник. Если приложение упало, приложите отчёт с экрана ошибки.

## Для разработчиков

Нужны JDK 17+ и Android SDK (platform 36).

```bash
./gradlew assembleDebug
```

APK (отдельный на каждую архитектуру): `app/build.nosync/outputs/apk/debug/`. Папки сборки названы `*.nosync`,
чтобы iCloud их не синхронизировал. Проверки перед коммитом:

```bash
./gradlew lintDebug test testDebugUnitTest
```

Выпуск, подпись и проверка парсеров Kotatsu — в [docs/release.md](docs/release.md), история изменений —
в [CHANGELOG.md](CHANGELOG.md).

| Модуль | Назначение |
|---|---|
| `app` | Точка входа, навигация, DI-граф |
| `core:*` | Модели, БД (Room), настройки (DataStore), сеть (OkHttp), картинки (Coil), тема |
| `data` | Репозитории |
| `source:api` | Интерфейс источников манги |
| `source:*` | Встроенные источники, локальные файлы, Komga, адаптер парсеров Kotatsu |
| `extension:lib` | API расширений Tachiyomi/Mihon (код Mihon, Apache-2.0, см. `extension/lib/LICENSE-mihon`) |
| `extension:manager` | Репозитории, установка и загрузка расширений |
| `translation:*` | Пайплайн перевода: OCR (ML Kit, manga-ocr), переводчики (ML Kit, Gemini, OpenAI-совместимые, DeepL) |
| `downloads`, `updates` | Загрузка глав и фоновая проверка обновлений |
| `feature:*` | Экраны |
| `tools:kotatsu-health` | Проверка парсеров Kotatsu и сборка списка рабочих |
| `build-logic` | Convention-плагины Gradle |

- [manga-ocr](https://github.com/kha-white/manga-ocr) — распознавание японского текста.
- [MangaDex](https://mangadex.org) и группы-переводчики, чьи переводы вы читаете.

Tsunayomi не размещает контент и не связан ни с одним источником: приложение показывает то, что отдают
подключённые вами источники.
